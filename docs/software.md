# โครงสร้างและการทำงานของโปรแกรม

โปรเจกต์พัฒนาด้วย **Arduino framework** ผ่าน **PlatformIO** บนบอร์ด **UNO R4 WiFi** และใช้ไลบรารี **LiquidCrystal_I2C** สำหรับจอ 16 × 2 ตาม [platformio.ini](https://github.com/BankTQMA/Bakuduino/blob/main/platformio.ini)

## ไฟล์สำคัญ

| ไฟล์ | หน้าที่ |
| --- | --- |
| [`src/main.cpp`](https://github.com/BankTQMA/Bakuduino/blob/main/src/main.cpp) | เริ่มอุปกรณ์ สุ่มด่าน สร้างโจทย์ รับปุ่ม จัดการเวลา X และผลแพ้ชนะ รวมกฎเขี้ยว |
| [`src/ModuleWave.h`](https://github.com/BankTQMA/Bakuduino/blob/main/src/ModuleWave.h) | จอ ขาอุปกรณ์ รูปคลื่น และตารางคลื่น |
| [`src/ModuleEye.h`](https://github.com/BankTQMA/Bakuduino/blob/main/src/ModuleEye.h) | กฎดวงตา การอ่านปุ่ม การส่งเสียง และการแสดงจอ |
| [`src/ModuleSpiral.h`](https://github.com/BankTQMA/Bakuduino/blob/main/src/ModuleSpiral.h) | กฎเกลียวและข้อความหน้ารอ/ผลจบเกม |
| [`src/ModuleStar.h`](https://github.com/BankTQMA/Bakuduino/blob/main/src/ModuleStar.h) | กฎดาวและการพิมพ์โจทย์/คำตอบลง Serial |

## วงจรข้อมูลหนึ่งด่าน

```text
สุ่มจำนวนเสียงหลอกตามหมายเลขด่าน
             ↓
สร้างเสียงต่ำ/กลาง/สูง และตำแหน่งเสียงหลอก
             ↓
ตัดเสียงหลอกออกเป็นชุดเสียงจริง
             ↓
เลือกตัวแก้โจทย์จากสัญลักษณ์ของด่าน
             ↓
เก็บคำตอบไว้ แล้วเล่นเสียงให้ผู้ควบคุมฟัง
             ↓
รับปุ่มทีละตัว เปรียบเทียบกับคำตอบ
             ↓
ผ่านด่าน / เล่นซ้ำ / เพิ่ม X และสร้างโจทย์ใหม่
```

โค้ดสร้างเสียงทั้งหมดก่อนแยกเสียงหลอกออก ดังนั้นผู้เล่นยังได้ยินเสียงหลักของตัวหลอก แต่จะมีติ๊กสั้นตามหลังเป็นเครื่องหมาย จากนั้นโปรแกรมคำนวณคำตอบด้วยเสียงจริงเท่านั้น ยกเว้นกฎเกลียวที่ต้องใช้ **จำนวน** เสียงหลอกด้วย [ดู `makeStage()` และ `solve()`](https://github.com/BankTQMA/Bakuduino/blob/main/src/main.cpp)

## ลำดับสัญลักษณ์

ตอนเริ่มเกม โปรแกรมใส่สัญลักษณ์ทั้งห้าลงในรายการ แล้วสลับลำดับแบบสุ่ม แต่ละรูปจึงปรากฏหนึ่งครั้งต่อเกม ขณะที่โจทย์เสียงถูกสร้างใหม่ในแต่ละด่าน [ดูส่วน `order` ใน main.cpp](https://github.com/BankTQMA/Bakuduino/blob/main/src/main.cpp)

## ตัวแปรสถานะที่มีผลต่อการเล่น

| ตัวแปร | ความหมาย |
| --- | --- |
| `stage` | หมายเลขด่านที่กำลังเล่น |
| `strikes` | จำนวนครั้งที่กดผิดสะสม |
| `endTime` | เวลาที่เกมต้องจบ |
| `tones` และ `decoy` | ระดับเสียงแต่ละตัวและตำแหน่งเสียงหลอก |
| `answer` และ `answerLen` | ลำดับปุ่มคำตอบและความยาว |
| `pressed` | จำนวนปุ่มในโจทย์ปัจจุบันที่กดถูกแล้ว |

เวลาเกมตั้งไว้ 300,000 มิลลิวินาทีหรือ 5 นาที เมื่อผ่านด่านโปรแกรมเล่นเสียงไล่ระดับขึ้น แล้วเพิ่ม `stage` ถ้ากดผิดจะเพิ่ม `strikes` และสร้างโจทย์ใหม่ในรอบถัดไปของด่านเดิม เมื่อผ่านครบห้าด่านจอขึ้น `DEFUSED!` ส่วนการพลาดครบสามครั้งหรือหมดเวลาขึ้น `*** BOOM ***` [ดูส่วนลูปหลัก](https://github.com/BankTQMA/Bakuduino/blob/main/src/main.cpp)

## อธิบายอัลกอริทึมทั้งห้าแบบสั้น ๆ

1. **คลื่น:** แปลงต่ำ/กลาง/สูงเป็น 1/2/3
2. **ดวงตา:** แปลงเป็น 3/1/4 แล้วกลับลำดับคำตอบ
3. **เขี้ยว:** แปลงเป็น 4/3/2 แต่เสียงจริงที่ซ้ำตัวก่อนหน้าให้กด 1
4. **เกลียว:** ถ้ามีเสียงหลอกสองตัว ใช้ค่าจากตารางฐานบวกหนึ่งโดยวน 4 กลับเป็น 1
5. **ดาว:** เริ่มที่ 4 แล้วเดิน +1/+2/+3 ตามเสียงจริงแต่ละตัว

รายละเอียดพร้อมตัวอย่างสำหรับผู้เล่นอยู่ใน [คู่มือถอดรหัส](manual/index.md) หน้านี้ตั้งใจอธิบายความสัมพันธ์ระหว่างไฟล์และลำดับทำงานของโปรแกรม เพื่อให้คนอ่านโค้ดตามต่อได้ง่ายขึ้น
