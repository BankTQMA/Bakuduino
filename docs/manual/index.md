# คู่มือถอดรหัส

แต่ละด่านจะแสดงสัญลักษณ์หนึ่งรูปที่มุมซ้ายบนของจอ สัญลักษณ์บอกว่าโจทย์เสียงชุดนั้นต้องใช้กฎหน้าไหน อ่านรูปก่อน ฟังเสียงให้จบ แล้วจึงเริ่มหาคำตอบ

| รูป | กฎ | สิ่งที่ต้องจำ |
| --- | --- | --- |
| ![คลื่น](../assets/icons/wave.svg) [คลื่น](wave.md) | แปลงตรงตามตาราง | ต่ำ 1 · กลาง 2 · สูง 3 |
| ![ดวงตา](../assets/icons/eye.svg) [ดวงตา](eye.md) | แปลงแล้วกลับลำดับ | อ่านคำตอบจากท้ายมาหน้า |
| ![เขี้ยว](../assets/icons/fang.svg) [เขี้ยว](fang.md) | เสียงจริงซ้ำให้กด 1 | เปรียบเทียบเสียงจริงตัวก่อนหน้า |
| ![เกลียว](../assets/icons/spiral.svg) [เกลียว](spiral.md) | เลือกตารางตามเสียงหลอก | นับเสียงที่มีติ๊กก่อน |
| ![ดาว](../assets/icons/star.svg) [ดาว](star.md) | เดินคำตอบเป็นลูกโซ่ | เริ่มคำนวณที่ปุ่ม 4 |

รูปพิกเซลในหน้านี้สร้างจากชุดข้อมูล `waveIcon`, `eyeIcon`, `fangIcon`, `spiralIcon` และ `starIcon` ใน [ซอร์สโค้ด](https://github.com/BankTQMA/Bakuduino/tree/main/src)

## วิธีอ่านโจทย์ร่วมกัน

1. ผู้ควบคุมเครื่องบอกชื่อรูปและด่าน
2. บอกเสียงทุกตัวตามลำดับ เช่น “สูง / ต่ำติ๊ก / กลาง / ต่ำ”
3. ผู้เชี่ยวชาญทวนรายการเสียง แล้วขีดทิ้งตัวที่มีติ๊ก
4. ตรวจจำนวนเสียงจริงกับช่อง `*` และ `-` บนจอ
5. เปิดหน้ากฎของรูปนั้น หาคำตอบให้ครบ แล้วให้ผู้ควบคุมทวนก่อนกด

**เสียงที่มีติ๊กคือเสียงหลอกทั้งตัว** ไม่ใช่ให้ตัดเพียงเสียงติ๊กแล้วเก็บเสียงหลักไว้ ตัวอย่าง “ต่ำ / สูงติ๊ก / กลาง” เหลือเสียงจริง “ต่ำ / กลาง” กฎเกลียวต้องรู้ด้วยว่ามีเสียงหลอกหนึ่งตัว

## จำนวนเสียงจริงในแต่ละด่าน

| ด่าน | เสียงจริง | เสียงหลอกมากที่สุด |
| ---: | ---: | ---: |
| 1 | 3 | 0 |
| 2 | 3 | 1 |
| 3 | 4 | 1 |
| 4 | 4 | 2 |
| 5 | 5 | 2 |

รูปสัญลักษณ์อาจมาอยู่ด่านใดก็ได้ เพราะลำดับถูกสลับทุกเกม จำนวนเสียงขึ้นกับ **หมายเลขด่าน** ไม่ได้ขึ้นกับรูป [ดูการสร้างโจทย์](https://github.com/BankTQMA/Bakuduino/blob/main/src/main.cpp)

## ถ้าฟังไม่ชัด

หลังไม่มีการกดประมาณ 6 วินาที เครื่องจะเล่นเสียง **ชุดเดิม** ซ้ำ แต่จะล้างจำนวนปุ่มที่กดถูกไปแล้ว จึงต้องเริ่มกดคำตอบตั้งแต่ตัวแรก รอบนี้ไม่เพิ่ม X หากกดผิด เครื่องจะเพิ่ม X และสร้าง **ชุดเสียงใหม่** ในสัญลักษณ์เดิม ต้องฟังและคำนวณใหม่ทั้งชุด [ดูฟังก์ชัน `playStage()`](https://github.com/BankTQMA/Bakuduino/blob/main/src/main.cpp)

ถ้าต้องการใช้คู่มือแบบพิมพ์ สามารถเปิด [Simon Says Manual.pdf](https://github.com/BankTQMA/Bakuduino/blob/main/Simon%20Says%20Manual.pdf)
