# ดวงตา

![สัญลักษณ์ดวงตาบนจอ LCD](../assets/icons/eye.svg)

กฎดวงตาใช้ **สองขั้น**: แปลงเสียงจริงด้วยตารางก่อน แล้วกลับลำดับคำตอบทั้งชุด ให้ตัวสุดท้ายมาอยู่ตัวแรก เสียงหลอกต้องตัดออกก่อนทำทั้งสองขั้น

| เสียงจริง | ต่ำ | กลาง | สูง |
| --- | ---: | ---: | ---: |
| ปุ่มจากตาราง | **3** | **1** | **4** |

โค้ด [`solveEye()`](https://github.com/BankTQMA/Bakuduino/blob/main/src/ModuleEye.h) วางผลลัพธ์ลงในตำแหน่งย้อนกลับ จึงได้ลำดับปุ่มหลังการกลับชุดทันที

## ตัวอย่างที่ 1: มีเสียงหลอกหนึ่งตัว

ได้ยิน: **สูง / ต่ำติ๊ก / กลาง / ต่ำ**

1. ตัด **ต่ำติ๊ก** ออก เหลือ **สูง / กลาง / ต่ำ**
2. แปลงจากตาราง ได้ **4 / 1 / 3**
3. กลับลำดับทั้งชุด ได้ **3 / 1 / 4**

**คำตอบ: 3 → 1 → 4**

## ตัวอย่างที่ 2: ไม่มีเสียงหลอก

ได้ยิน: **ต่ำ / กลาง / สูง / ต่ำ**

แปลงได้ **3 / 1 / 4 / 3** แล้วอ่านจากท้ายมาหน้า

**คำตอบ: 3 → 4 → 1 → 3**

## จุดที่ควรตรวจ

- ผู้ควบคุมเครื่องควรรายงานเสียง **ตามลำดับที่ได้ยิน** ผู้เชี่ยวชาญเป็นคนกลับลำดับคำตอบ
- กลับลำดับเพียงครั้งเดียว
- ถ้ามีเสียงหลอกตรงกลาง ให้ตัดออกก่อน แล้วจึงหาตัวสุดท้ายของชุดเสียงจริง
