# คลื่น

![สัญลักษณ์คลื่นบนจอ LCD](../assets/icons/wave.svg)

รูปคลื่นเป็นกฎที่ตรงที่สุดในเกม ฟังเสียงให้ครบ ตัดเสียงหลอก แล้วแปลงเสียงจริงแต่ละตัวเป็นหมายเลขปุ่มตามตาราง **กดตามลำดับที่ได้ยิน**

| เสียงจริง | ต่ำ | กลาง | สูง |
| --- | ---: | ---: | ---: |
| ปุ่มที่กด | **1** | **2** | **3** |

กฎนี้อยู่ใน [`solveWave()`](https://github.com/BankTQMA/Bakuduino/blob/main/src/ModuleWave.h)

## ตัวอย่างที่ 1: ไม่มีเสียงหลอก

ได้ยิน: **ต่ำ / สูง / กลาง**

เสียงจริงยังเป็น **ต่ำ / สูง / กลาง** จึงแปลงได้ **1 / 3 / 2**

**คำตอบ: 1 → 3 → 2**

## ตัวอย่างที่ 2: มีเสียงหลอกหนึ่งตัว

ได้ยิน: **สูง / ต่ำติ๊ก / สูง / ต่ำ**

ตัด **ต่ำติ๊ก** ออก เหลือ **สูง / สูง / ต่ำ** เสียงสูงซ้ำกันสองตัวก็ต้องกดปุ่ม 3 สองครั้ง

**คำตอบ: 3 → 3 → 1**

## จุดที่ควรตรวจ

- ปุ่ม **4** ไม่อยู่ในคำตอบของกฎคลื่น ถ้าคำนวณได้ 4 ให้ตรวจตารางอีกครั้ง
- เสียงจริงที่ซ้ำกันให้กดปุ่มเดิมซ้ำ
- เสียงหลอกต้องตัดออกทั้งตัวก่อนแปลงเสียง
