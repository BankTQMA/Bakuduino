# เกลียว

![สัญลักษณ์เกลียวบนจอ LCD](../assets/icons/spiral.svg)

กฎเกลียวเริ่มจาก **นับจำนวนเสียงหลอก** เสียงที่มีติ๊กไม่ใช่คำตอบ แต่จำนวนของมันใช้เลือกแถวตาราง จากนั้นจึงแปลงเฉพาะเสียงจริงตามลำดับที่ได้ยิน

| จำนวนเสียงหลอก | ต่ำ | กลาง | สูง |
| --- | ---: | ---: | ---: |
| 0 หรือ 1 ตัว | **2** | **4** | **1** |
| 2 ตัว | **3** | **1** | **2** |

ตารางแถวล่างเท่ากับค่าแถวบน **บวก 1** โดย 4 วนกลับเป็น 1 โค้ด [`solveSpiral()`](https://github.com/BankTQMA/Bakuduino/blob/main/src/ModuleSpiral.h) ใช้แถวล่างเมื่อจำนวนเสียงหลอกตั้งแต่สองตัวขึ้นไป ในเกมปัจจุบันเสียงหลอกมากสุดคือสองตัว

## ตัวอย่างที่ 1: เสียงหลอกหนึ่งตัว

ได้ยิน: **กลาง / ต่ำติ๊ก / สูง / ต่ำ**

1. นับเสียงหลอกได้ **1 ตัว** จึงใช้แถวบน
2. ตัดต่ำติ๊ก เหลือ **กลาง / สูง / ต่ำ**
3. แปลงได้ **4 / 1 / 2**

**คำตอบ: 4 → 1 → 2**

## ตัวอย่างที่ 2: เสียงหลอกสองตัว

ได้ยิน: **ต่ำติ๊ก / กลาง / สูงติ๊ก / ต่ำ / สูง / กลาง**

เสียงหลอกมี **2 ตัว** ใช้แถวล่างตลอดชุด เสียงจริงคือ **กลาง / ต่ำ / สูง / กลาง**

**คำตอบ: 1 → 3 → 2 → 1**

## จุดที่ควรตรวจ

- เลือกแถวก่อนเริ่มแปลงเสียงจริง และใช้แถวเดียวกันตลอดชุด
- ถ้าใช้แถวล่างแล้ว **ไม่ต้องบวก 1 ซ้ำ**
- เสียงหลอกสองตัวเกิดได้ในด่าน 4 และ 5 ตามจำนวนสูงสุดที่โปรแกรมกำหนด
