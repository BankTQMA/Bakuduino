เกี่ยวกับ Bakuduino

แนวคิดของโครงงาน

Bakuduino นำรูปแบบเกมกู้ระเบิดที่ต้องสื่อสารกันมาอยู่บนอุปกรณ์ที่จับต้องได้ ผู้เล่นคนหนึ่งอยู่กับเครื่องจริง: มีจอแสดงสถานะ ปุ่มกด และเสียงสัญญาณ อีกคนถือคู่มือที่บอกวิธีแปลสัญญาณ แต่ไม่เห็นสิ่งที่เกิดขึ้นหน้าเครื่อง คำตอบจึงไม่ได้อยู่กับใครคนเดียว ต้องเกิดจากการเล่า ฟัง ทวน และลงมือกดร่วมกัน

ชื่อ Bakuduino มาจาก Bakudan ซึ่งเป็นคำภาษาญี่ปุ่นที่หมายถึงระเบิด ผสมกับ Arduino ซึ่งเป็นบอร์ดที่ใช้พัฒนาโครงงาน ที่มาของชื่อและแรงบันดาลใจจาก Keep Talking and Nobody Explodes ระบุไว้ใน README ของโปรเจกต์

เกมและคู่มือในโครงงานใช้ชื่อ Simon Says: เครื่องเล่นลำดับเสียง ผู้เล่นต้องจำแนกและตอบกลับด้วยปุ่มตามกฎของรูปที่จอแสดง ชื่อดังกล่าวใช้กับเกมของโครงงานนี้ ไม่ได้หมายความว่ากติกาจะตรงกับโมดูลชื่อเดียวกันในเกมต้นแรงบันดาลใจ

สิ่งที่โครงงานต้องการให้ผู้เล่นทำ

  • สังเกต สัญลักษณ์ ด่าน เวลา และเครื่องหมายพลาดบนจอ
  • ฟัง เสียงต่ำ กลาง สูง และแยกเสียงที่มีติ๊กตามหลัง
  • สื่อสาร ลำดับเสียงให้คนอ่านคู่มือเข้าใจโดยไม่สลับตำแหน่ง
  • ถอดรหัส ด้วยกฎเฉพาะของสัญลักษณ์ในด่านนั้น
  • ตัดสินใจร่วมกัน ว่าคำตอบพร้อมแล้วหรือควรรอฟังซ้ำ

ความสนุกของเกมอยู่ที่ข้อมูลไม่ครบในมือคนใดคนหนึ่ง ต่อให้รู้ตารางแปลงเสียงทั้งหมด คนอ่านคู่มือก็ยังตอบไม่ได้จนกว่าจะได้รับคำอธิบายจากคนหน้าเครื่อง และต่อให้คนหน้าเครื่องฟังเสียงชัด ก็ยังต้องอาศัยกฎจากคู่มือ

เกมมีห้าด่าน รูปทั้งห้าถูกสลับลำดับในแต่ละรอบ มีเวลารวม 5 นาที และจบเมื่อผ่านครบทุกด่าน เวลาหมด หรือพลาดครบสามครั้ง ดูการจัดการด่านและเวลาในซอร์สโค้ด

สิ่งที่ได้จากการทำโครงงาน

เว็บไซต์นี้อธิบายทั้งประสบการณ์ของผู้เล่นและการสร้างอุปกรณ์จริง ผู้ที่สนใจสามารถเริ่มจาก วิธีเล่น ก่อน แล้วค่อยไปดู วงจร และ โครงสร้างโปรแกรม เพื่อเห็นว่าอินพุตจากปุ่ม เอาต์พุตจากจอและเสียง และกติกาในซอฟต์แวร์เชื่อมกันอย่างไร
